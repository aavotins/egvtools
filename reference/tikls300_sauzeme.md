# Example 300-m grid polygons

A reduced 300-m grid used in spatial examples.

## Usage

``` r
tikls300_sauzeme
```

## Format

An `sf` object containing polygon geometries and grid identifiers:

- `rinda300`: identificator of 300 m grid cell.

- `x`: `sf geometry` field.

## Source

Derived from a reduced section of the Latvian 300-m harmonization grid.

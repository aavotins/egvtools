# Example 500-m grid points

Point centres of a reduced 500-m grid used in spatial examples.

## Usage

``` r
pts500_sauzeme
```

## Format

An `sf` object containing point geometries and grid identifiers:

- `rinda500`: identificator of 500 m grid cell.

- `X`: EPSG:3059 x-coordinate of centroid.

- `Y`: EPSG:3059 y-coordinate of centroid.

- `tks50km`: identificator of topographic map's 50 km page.

- `x`: `sf geometry` field.

## Source

Derived from a reduced section of the Latvian 500-m harmonization grid.

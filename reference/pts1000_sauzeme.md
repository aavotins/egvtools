# Example 1000-m grid points

Point centres of a reduced 1000-m grid used in spatial examples.

## Usage

``` r
pts1000_sauzeme
```

## Format

An `sf` object containing point geometries and grid identifiers:

- `ID1km`: identificator of 1 km grid cell.

- `tks50km`: identificator of topographic map's 50 km page.

- `geometry`: `sf geometry` field.

## Source

Derived from a reduced section of the Latvian 1000-m harmonization grid.
